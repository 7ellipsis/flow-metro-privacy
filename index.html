Flow Metro – Privacy Policy

App: Flow Metro – Tile Launcher
Developer: Ashay Mandwarya / 7ellipsis
Last updated: 23 September 2026

Overview

Flow Metro is an independent Android home-screen launcher. It is not affiliated with Microsoft. There is no Flow Metro account or advertising profile. Most data is read and processed on the device; the limited transfers below happen only when you choose the related feature.

On-device permissions

  • AccessibilityService – Only after a separate, prominent in-app disclosure and your explicit acceptance. It receives window-change events, the foreground package and volume-key events to keep optional navigation overlays, the volume panel and the global Action Center gesture in sync. It cannot retrieve window content or accessibility text, take screenshots, read messages/passwords, or share service data.
  • Contacts, Call Log and SMS – People and Threads use these providers on-device for contacts, recent calls and messaging. Threads requests the Android default SMS role before restricted SMS permissions.
  • Calendar – Day Sense reads and writes calendar events on-device for the calendar tile and reminders.
  • Photos, videos and audio – Selected local media powers tiles, wallpapers and playback. Flow does not upload these files by itself.
  • Notifications and installed apps – Notification access mirrors alerts into Flow's Action Center and tiles; QUERY_ALL_PACKAGES lists launchable apps for the launcher. Both stay on-device.
  • Files – File Sense can browse and manage local files after you grant Android all-files access. File names and contents stay local unless you explicitly share or transfer them.
  • Foreground work – A visible foreground service runs only for a user-enabled lock screen (normal, Glance AOD or transflective surface) or a user-started File Sense operation. It stops when the feature or operation ends.
  • Microphone and device controls – Microphone is used only for keyboard voice input after you choose it. Overlay and write-settings access is used only for the Flow controls you enable; Android presents the system grant.

Data that leaves the device

  • Weather: optional approximate coordinates (device location, IP-derived location or your default city) are sent over HTTPS to Open-Meteo to return a forecast. You can use a default city or leave weather unused.
  • Wallpaper: optional image requests contact Bing/Microsoft; no personal content is attached.
  • Cloud storage: if you start a Google Drive, OneDrive or Dropbox connection, OAuth codes/tokens and the files you explicitly transfer go to that provider. Tokens are stored encrypted on-device and disconnecting removes them.

Telemetry and advertising ID

The current Play release has no google-services.json configuration and removes advertising-ID permissions from the merged manifest. Metrics therefore stays in local mode: feature events are debug-log only and no analytics or crash report is sent to Firebase. There are no ads.

Deletion and retention

Flow Metro has no account or server-side personal-data store. Local settings and cached data can be removed from Android app settings or by uninstalling. Disconnect any cloud provider in File Sense to remove its encrypted tokens. Third-party services apply their own retention policies; see their policies when you use them.

Children's privacy

Flow Metro is intended for adults and is not directed at children. We do not knowingly collect data from children.
